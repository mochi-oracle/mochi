# Public history

This repository is a retrospective export of Mochi development work. The project work began in late July 2026. The current release snapshot is organized into 250 small, related file groups, using editorial dates from July 25 through September 28, 2026.

The grouping follows the original 250-part export, with subsequent fixes incorporated into their related components. Each commit introduces a file or a related group of files from the current snapshot. Intermediate commits are not guaranteed to build or run on their own.

These are reconstructed commit dates, not original timestamps, a claim of 250 independently recorded development sessions, or independent proof of when work happened. GitHub creation and push activity record publication activity separately.

All first-party commits use neutral project authorship. The approved publishing account can appear in Activity; contributor attribution and publishing authentication are separate. Required third-party license notices and attribution are preserved. This history replaces the three-commit rebuild; the earlier repositories and source snapshots are retained privately.

The user-facing product remains a research preview, with live reviews and payments disabled. Repository components do not imply that every protocol feature is deployed. See the [README](../README.md) and [claim research notes](../services/claims/README.md) for current scope.
