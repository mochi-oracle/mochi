# Security

Report vulnerabilities privately through **GitHub security advisories** on this repository ("Report a vulnerability"
on the Security tab). Do not open public issues for security problems.

Please include the affected contract or service, the impact, and a proof of concept or reproduction steps. We aim to
acknowledge reports within three days.

In scope: everything under `contracts/src`, the enclave services (`services/intake`, `services/juror`,
`services/consensus`), the attestation and quote-verification code (`packages/tee`, `packages/aci`), and the SDK.
Third-party code under `contracts/lib` and `contracts/vendor` should be reported upstream as well.
